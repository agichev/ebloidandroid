# Ebloid Android 🐸

Официальный Android-клиент для [eblo.id](https://eblo.id), разработанный на **Jetpack Compose** и **Material 3**.

Клиент предоставляет полноценный нативный мобильный опыт: оптимизированную полноэкранную ленту публикаций, удаление навязчивых баннеров согласий, встроенный менеджер загрузок файлов и аутентичную стилизацию под оригинальный дизайн платформы.

---

## ✨ Особенности и функционал

- 🎨 **Аутентичный дизайн**: 
  - Splash Screen с оригинальным логотипом `eblo-logo.svg` и скелетоном публикации в фирменных цветах (`--surface-ground: #202020`, `--brand: #789D2A`).
  - Адаптивная иконка приложения без лишних белых рамок лаунчера.
  - Устранение синего браузерного эффекта выделения при тапах (`tap-highlight`).
- 📱 **Twitter/X-стиль ленты (Full-bleed timeline)**:
  - Публикации и медиа растягиваются на всю ширину экрана без лишних боковых отступов.
  - Центрированная панель разделов («Лента», «Подписки», «Фильтрация»).
  - Удалена избыточная кнопка перехода в полноэкранный режим из шапки.
- 🚫 **Блокировка баннеров**:
  - Полное скрытие модальных окон согласия с Яндекс.Метрикой на eblo.id.
  - Автоматическая очистка cookie/consent баннеров Twitch при авторизации.
- ⚡ **Высокая скорость и оптимизация**:
  - Блокировка тяжелых трекеров и вебвизоров (`mc.yandex.ru`) на уровне `WebViewClient`.
  - Включен аппаратный предрендеринг (`offscreenPreRaster`) и кэширование статических ресурсов.
- 📥 **Нативное скачивание контента**:
  - Интеграция с Android `DownloadManager` — сохранение медиа и файлов прямо в папку «Загрузки» устройства с системными уведомлениями.
- 🔑 **Полная цифровая подпись**:
  - Сборка подписана схемами v1, v2, v3 для стабильной установки на современные версии Android (Android 8.0+ / API 26+).

---

## 🛠 Стек технологий

- **Язык**: Kotlin 2.0+
- **UI Toolkit**: Jetpack Compose (BOM 2024.10.01), Material 3
- **Web Container**: AndroidX WebKit 1.12+, JavaScript & CSS Injection
- **Сборщик**: Gradle 8.11+, Android Gradle Plugin 8.7+
- **Архитектура**: Single Activity, Hardware Accelerated

---

## 🚀 Сборка проекта

### Требования
- JDK 17+
- Android SDK (compileSdk 35, minSdk 26)

### Команды для сборки

```bash
# Клонирование репозитория
git clone https://github.com/agichev/ebloidandroid.git
cd ebloidandroid

# Сборка подписанного Release APK
./gradlew assembleRelease
```

Собранный файл будет находиться в директории:
`app/build/outputs/apk/release/app-release.apk`
